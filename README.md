# Ojus Mohan

Department of Chemical Engineering, IIT Bombay · CARES Lab

I work on computational catalysis and materials: density functional theory (DFT), machine-learned
interatomic potentials (MLIPs) and their combination for searching surfaces, interfaces and adsorbates.

**Current focus**
- Fine-tuning foundation MLIPs (MACE) on DFT data, with uncertainty-driven active learning
- MLIP-guided global optimisation followed by DFT validation (VASP, PBE+D3)
- Photoelectrocatalysis on CIGS-based photocathodes and supported metal layers
